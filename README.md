# Football_Quiz_App
A personal project that showcases learning of Jetpack Compose and the fundamentals behind it, in creating a interactive, engaging
quiz app about football, where players can select categories to be quizzed on. From players, stadiums, club logos etc, there's always
something for the casual user to enjoy. The questions appear in the form of just text or pictures with text, and the user chooses between
four different options.

## Prerequisites

- Java JDK 17 or later installed on your local machine.
- Environment variable 'JAVA_HOME' must be set (java --version & javac -version must give info about installed JDK).
- A version control system (preferably Git) installed on your machine.
- Android Studio installed and up-to-date.
- Up-to-date SDK build tools for compiling and debugging.
- Emulator or physical device with Android version 9.0 or over (Developer options must be enabled).

## Installation

Follow the steps below for a smooth install:

1. Clone the repo locally.
2. Open the project folder in Android Studio.
3. Sync the project to download all relevant dependencies.
4. Build the project
     - If you plan on using an emulator, select your preferred device and deploy the app on it.
     - If you have a physical device connected, select it instead.
5. If, for any reason, some tools are missing on your device, install the necessary tools and try again.
